# Deep Winter (Forge 1.20.1)

Зимний апокалипсис: мир постепенно замерзает вокруг игроков.

| Стадия | Дни (по умолчанию) | Что происходит |
|--------|--------------------|----------------|
| 0 | 0-4   | Всё спокойно |
| 1 | 5-14  | Появляется тонкий снег |
| 2 | 15-29 | Вода покрывается льдом, листва облетает, цветы/посевы/трава гибнут, снег толще, холод на открытом небе |
| 3 | 30+   | Трава мёртвая, очень толстый снег, холод даже под крышей (выше Y=50) |

- Мир меняется **постепенно** и только вокруг игроков (радиус 64 блока). Блоки возле факелов и других источников света (яркость 11+) не замерзают.
- Холод: пока не установлен **Cold Sweat**, мод сам морозит игрока (синий иней, потом урон). Если Cold Sweat есть, свой холод отключается автоматически, чтобы не дублировать.
- Источники тепла (тег `deepwinter:heat_sources`): горящие костры и печи, огонь, лава, магма, а также Create Blaze Burner и нагреватели Mekanism, если они есть. Тёплая одежда (тег `deepwinter:warm_clothing`): кожаная броня.
- Всё настраивается в `config/deepwinter-common.toml` (дни стадий, радиус, скорость, режим холода).

Команды: `/deepwinter` (день и стадия), `/deepwinter day 30` и `/deepwinter reset` (для оператора, чтобы проверить стадии).

## Как собрать

### Способ 1: без установки Java (через GitHub)
1. Создай бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузи в него ВСЁ содержимое этой папки (кнопка Add file, затем Upload files; папка `.github` обязательна).
3. Открой вкладку **Actions**: сборка запустится сама (3-6 минут).
4. Открой завершённый запуск и скачай архив **deepwinter-mod** внизу страницы. Внутри лежит `deepwinter-0.1.0.jar`. Его положи в папку `mods`.

### Способ 2: на своём компьютере
Нужна любая JDK 17-21 (например, Temurin с adoptium.net). В папке проекта:

    gradlew.bat build        (Windows)
    ./gradlew build          (Linux/macOS)

Готовый мод: `build/libs/deepwinter-0.1.0.jar`.
